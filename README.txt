# انهض — PWA 105 يوم

## ملفات المشروع
- `index.html`: التطبيق.
- `manifest.webmanifest`: إعدادات التثبيت.
- `sw.js`: تشغيل أوفلاين وتوجيه إشعار الاختبار.
- `icon.svg`: أيقونة التطبيق.

## التثبيت على Android / Chrome
1. ارفع محتويات هذا المجلد إلى استضافة HTTPS (مثل GitHub Pages أو Netlify). لا تفتح `index.html` كملف محلي إذا أردت خصائص PWA.
2. افتح الرابط في Chrome على أندرويد.
3. اختر «تثبيت التطبيق» إذا ظهرت، أو قائمة ⋮ ثم «إضافة إلى الشاشة الرئيسية».
4. داخل التطبيق: افتح إعدادات التذكير، اختر الوقت، ثم اضغط «اختبار الإشعار» واسمح بالإشعارات.

## الإشعارات — توضيح تقني
- إشعار الاختبار يعمل بعد موافقة المستخدم.
- التذكير المحلي في هذه النسخة يُطلق عندما تكون الصفحة/التطبيق نشطًا؛ عند فتح التطبيق يفحص وقت التذكير ويطلقه إذا مرّ الوقت.
- الإشعارات اليومية المضمونة أثناء إغلاق التطبيق/الهاتف تحتاج Push service مع خادم (Web Push) وجدولة من جهة الخادم؛ PWA وحدها لا تضمن تشغيل مؤقت يومي في الخلفية على Android.

## البيانات
التقييمات والبونص محفوظة في LocalStorage على هذا الجهاز/المتصفح. استخدم «نسخ احتياطي» داخل التطبيق لتنزيل JSON واستعادة بياناتك لاحقًا.
